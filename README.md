# 🇹🇭 Thaï 101 - Apprendre à lire le Thaï

Application interactive pour apprendre à lire le thaï étape par étape, pensée pour les francophones débutants complets.

## 🎯 Objectif

Passer de zéro à la lecture autonome de syllabes et mots thaïs, en suivant une progression logique :

1. **Consonnes** — formes et sons, regroupées par proximité visuelle plutôt que par ordre alphabétique traditionnel
2. **Voyelles** — positions et sonorités
3. **Tons** — règles tonales, une fois les bases de lecture acquises
4. **Lecture guidée** — mots et phrases simples
5. **Exercices** — pratique et révision

## 🛠️ Stack technique

- [Streamlit](https://streamlit.io/) — framework Python pour l'interface
- Déployé sur Streamlit Community Cloud

## 🚀 Lancer en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📱 Compatible mobile

L'interface est optimisée pour une lecture confortable aussi bien sur ordinateur que sur smartphone.
